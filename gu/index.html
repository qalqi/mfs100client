મંત્રા MFS100 વેબ બ્રિજ લાઇવ ટેસ્ટર

ગૂગલ ક્રોમ દ્વારા તમારા કોમ્પ્યુટર પર મંત્રા MFS100 ફિંગરપ્રિન્ટ સ્કેનરનું પરીક્ષણ કરો (પોર્ટ 8004)

OS: Windows 11 / 10 Hardware: MFS100 (L0) Browser: Google Chrome Port: 8004
💡 GitHub Pages (HTTPS) પર ચલાવવા માટેની સૂચના: આ પેજ https:// પર લોડ થાય છે, તેથી ક્રોમ http://127.0.0.1:8004 ને બ્લોક કરે છે.
મંજૂરી આપવા માટે: એડ્રેસ બારમાં લૉક / ટ્યુન આઇકોન પર ક્લિક કરો → Site settings → Insecure content ને Allow (મંજૂરી આપો) કરો.

🚀 તમારા પોતાના PC પર ચલાવવાના સરળ પગલાં

  • 1
    બ્રિજ ડાઉનલોડ કરો: 📥 Download ZIP પર ક્લિક કરીને ઝિપ ફાઇલ ડાઉનલોડ કરો અથવા git clone https://github.com/qalqi/mfs100client.git કરો. તેને કોઈપણ ફોલ્ડરમાં અનઝિપ કરો.
  • 2
    સ્કેનર કનેક્ટ કરો: મંત્રા MFS100 સ્કેનરને USB પોર્ટમાં લગાવો. ખાતરી કરો કે ડેસ્કટોપ પર અન્ય કોઈપણ ટેસ્ટ એપ (જેમ કે Mantra MFS100 Test) બંધ (Closed) હોય જેથી USB પોર્ટ ખાલી રહે.
  • 3
    બ્રિજ શરૂ કરો: ફોલ્ડરમાં રહેલી start.bat ફાઇલ પર ડબલ-ક્લિક કરો. સ્ક્રીન પર [OK] MFS100 Hardware Bridge listening on port 8004 દેખાશે. આ વિન્ડો ચાલુ રાખો.
  • 4
    ક્રોમમાં મંજૂરી આપો: સાઇટ સેટિંગ્સમાં જઈને Insecure content ને Allow કરો.
  • 5
    ફિંગરપ્રિન્ટ સ્કેન કરો: નીચે **'1. સ્કેનર માહિતી તપાસો'** પર ક્લિક કરો, પછી **'2. ફિંગરપ્રિન્ટ કેપ્ચર કરો'** પર ક્લિક કરો. સ્કેનરની લાલ લાઇટ થશે, તમારી આંગળી સ્કેનર પર મૂકો!
