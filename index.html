🚀 How to Run the Bridge on Your Own PC
  • 1
    Download the Bridge: 📥 Download ZIP or clone via git clone https://github.com/qalqi/mfs100client.git. Extract it to any folder.
  • 2
    Connect Scanner & Close Other Tools: Plug your Mantra MFS100 scanner into a USB port. Make sure any desktop test app (like Mantra MFS100 Test) is closed so the USB port is free.
  • 3
    Launch the Bridge: Double-click start.bat inside the extracted folder. You will see [OK] MFS100 Hardware Bridge listening on port 8004. Keep this window open.
  • 4
    Allow Chrome Local Connection: Because this web page runs on https://, click the tune / lock icon in Chrome's address bar → Site settings → set Insecure content to Allow.
  • 5
    Test Below or on Your Portal: Click "1. Check Scanner Info" below to confirm connection, then click "2. Capture Fingerprint"! It will work directly on this page and on your government e-filing portal.
