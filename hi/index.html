मंत्रा MFS100 वेब ब्रिज लाइव परीक्षक

अपने कंप्यूटर पर गूगल क्रोम ब्राउज़र से मंत्रा MFS100 फिंगरप्रिंट स्कैनर का परीक्षण करें (पोर्ट 8004)

OS: Windows 11 / 10 Hardware: MFS100 (L0) Browser: Google Chrome Port: 8004
💡 गिटहब पेजेस (HTTPS) पर चलाने हेतु निर्देश: यह पेज https:// पर लोड होता है, इसलिए क्रोम सुरक्षा कारणों से http://127.0.0.1:8004 को ब्लॉक करता है।
अनुमति देने के लिए: एड्रेस बार में लॉक / ट्यून आइकन पर क्लिक करें → Site settings → Insecure content को Allow (अनुमति दें) करें।

🚀 अपने कंप्यूटर पर चलाने के आसान चरण

  • 1
    ब्रिज डाउनलोड करें: 📥 Download ZIP पर क्लिक करें या git clone https://github.com/qalqi/mfs100client.git करें। इसे किसी भी फोल्डर में अनज़िप करें।
  • 2
    स्कैनर कनेक्ट करें: अपने मंत्रा MFS100 स्कैनर को USB पोर्ट में लगाएं। ध्यान दें कि कोई अन्य टेस्ट सॉफ्टवेयर (जैसे Mantra MFS100 Test) बंद (Closed) होना चाहिए ताकि USB पोर्ट खाली रहे।
  • 3
    ब्रिज शुरू करें: फोल्डर में मौजूद start.bat फाइल पर डबल-क्लिक करें। आपको [OK] MFS100 Hardware Bridge listening on port 8004 लिखा हुआ दिखाई देगा। इस विंडो को खुला रखें।
  • 4
    क्रोम में अनुमति दें: एड्रेस बार में लॉक आइकन → Site settings → Insecure content को Allow करें।
  • 5
    फिंगरप्रिंट स्कैन करें: नीचे '1. स्कैनर जानकारी जांचें' पर क्लिक करें, फिर '2. फिंगरप्रिंट कैप्चर करें' पर क्लिक करें। स्कैनर की लाल लाइट जल जाएगी, अपनी उंगली स्कैनर पर रखें!
